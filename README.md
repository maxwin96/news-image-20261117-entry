**World News in One Image — Tuesday, 17 November 2026.** A program that draws a single 1024×1024 image summing up the day's world news: the Crimea bridge span falling after a Ukrainian strike, Iranian drones hitting a US radar in Bahrain, Trump arriving in Manila for the ASEAN summit, Mongolia's president announcing his resignation, the UK sanctioning settlement firms, and a rocket failure losing 40 satellites.

## Run it

```sh
python3 main.py
# writes out/entry.png (or $MAKEFUN_OUTPUT_DIR/entry.png)
```

Pure Python 3 standard library (zlib only). No network, no randomness, no wall clock: two runs produce byte-identical PNG output.
